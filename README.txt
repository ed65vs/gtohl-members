GTOHL Members Face Quiz

Upload the contents of this folder to the ROOT of your GitHub repository.

Required file:
  index.html

GitHub Pages setup:
  1. Open the repository on GitHub.
  2. Settings -> Pages.
  3. Under "Build and deployment":
     Source: Deploy from a branch
     Branch: main
     Folder: / (root)
  4. Save.
  5. Wait about 1-2 minutes for GitHub Pages to publish.

Your URL will normally be:
  https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/

The quiz is self-contained:
  - all 48 player faces are embedded in index.html
  - no image folder is required
  - works in Safari/Chrome when served as a website
  - mobile and desktop friendly
